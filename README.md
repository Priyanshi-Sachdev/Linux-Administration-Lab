# Linux Administration Lab 🐧


This repository contains lab exercises, system administration commands, and practical coursework solutions for Linux Administration at IILM University.

## 📁 Repository Structure

* **Experiments:** Organized folders containing terminal commands and output screenshots.
* **Environment:** Linux Terminal / Ubuntu (VirtualBox).

## 🛠️ Key Topics Covered

* **File System & Navigation:** Directory management and path manipulation
* **Permissions & Ownership:** User access control and file security
* **Process Management:** Monitoring system processes and execution
* **Shell Scripting:** Automation tasks and basic scripts
